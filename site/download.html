Download and install

Every change to main is tested and published as a Docker image. Pull it, give it a volume and a few settings, and you are running.

Pull the image

Published to the GitHub Container Registry for linux/amd64. latest follows main; every build is also tagged with its commit (sha-…) so you can pin one.

docker pull ghcr.io/goodguy140/finance-tracker-app:latest

Run it with Docker Compose

Save this as compose.yaml, fill in the three secrets, and run docker compose up -d. The database lives at /data/app.db on the volume, and migrations run on every start.

services:
  finance-tracker:
    image: ghcr.io/goodguy140/finance-tracker-app:latest
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - finance-data:/data
    environment:
      NEXTAUTH_URL: https://finance.example.com
      NEXTAUTH_SECRET: change-me          # openssl rand -base64 48
      SERVER_SETTINGS_ENCRYPTION_KEY: change-me-to-32-or-more-characters
      AUTH_TRUST_HOST: "true"             # behind a reverse proxy

volumes:
  finance-data:

Create the admin account

Open your NEXTAUTH_URL and sign up. The first account becomes the server admin (set INITIAL_ADMIN_EMAIL to choose who). Public signup is closed after that unless you turn it on under Settings → Server admin.

GET /api/health returns 200 once the app is up, which suits a reverse proxy or uptime check.

Settings

Most optional settings can also be changed in the app under Settings → Server admin; a value in the environment wins.

VariableWhat it does
NEXTAUTH_URLRequired. The public URL people visit. Passkeys are bound to this hostname.
NEXTAUTH_SECRETRequired. Session signing secret.
SERVER_SETTINGS_ENCRYPTION_KEYRequired. At least 32 characters. Encrypts SSO and Plaid credentials stored in the database.
AUTH_TRUST_HOSTSet to true behind a reverse proxy.
INITIAL_ADMIN_EMAILOnly this email becomes admin on first signup.
ALLOW_PUBLIC_SIGNUPOpen signup to anyone who can reach the server. Off by default.
SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, SMTP_FROMEmail for password resets and budget alerts.
PLAID_CLIENT_ID, PLAID_SECRET, PLAID_ENVBank sync through Plaid. PLAID_ENV is sandbox or production.
AUTHENTIK_*Single sign-on with Authentik. Google sign-in is set up in the app.

The full list is in the README.

Other ways to get it

Run from source

Needs Node.js 22. No environment variables are needed for development.

git clone https://github.com/Goodguy140/finance-tracker
cd finance-tracker
npm ci
npm run db:deploy
npm run dev
